# StreakWOK (Streak Workout)

Aplikasi mobile untuk workout dengan teman yang bersistem gamifikasi streak dengan teman. Dengan validasi gerakan dengan kamera dalam tiap repetisi. Setiap repetisi dihitung dengan deteksi kamera handphone secara otomatis. Jika ada anggota yang tidak melakukan workout harian dalam beberapa hari, maka streak akan mati untuk sementara menunggu di-revive, atau bahkan hangus.

---

## 🚀 Getting Started

### Prerequisites
- Android Smartphone (Android 8.0+) atau Browser Google Chrome (untuk simulator)
- Flutter SDK (>= 3.0.0) & Dart SDK

### Installation & Run

#### 1. Jalankan Prototype di Desktop (1-Klik)
Klik ganda file `Launch_StreakWok.bat` untuk membuka simulator mobile secara otomatis di browser Chrome.

#### 2. Pasang di Smartphone Android (APK)
Unduh dan pasang file `StreakWok.apk` langsung ke perangkat Android Anda.

---

## 📦 Tech Stack
- **Mobile Framework:** Flutter / Android Native
- **Computer Vision:** Google MediaPipe Pose Detection
- **Cloud Backend:** Firebase Authentication & Firestore
